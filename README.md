# 🧮 TPA: ETEC Uirapuru

Atividades da disciplina **Técnicas de Programação e Algoritmos** (2024), do curso técnico em Desenvolvimento de Sistemas da ETEC Uirapuru.

| Atividade | Descrição | Tecnologias | Data |
|---|---|---|---|
| [`01-estrutura-de-decisao`](01-estrutura-de-decisao/) | Estruturas de decisão simples e compostas, em pseudocódigo e em JavaScript | VisualG, JavaScript | 04/2024 |
| [`02-exercicios-visualg`](02-exercicios-visualg/) | Exercícios de algoritmos: IMC, idade, salário, plano cartesiano, maior de três números e outros | VisualG | 04/2024 a 05/2024 |

> Em `02-exercicios-visualg`, a pasta `Exercícios - Copia` tem versões diferentes de dois exercícios (`NOME.ALG` e `MAIOR DE IDADE(EX.1).ALG`), por isso foi mantida.

## Como abrir

Os arquivos `.ALG` abrem no [VisualG](https://visualg3.com.br/). O `IfElse.js` roda com `node IfElse.js`.

## Sobre este repositório

O conteúdo veio da pasta `TPA/` do antigo repositório `ETEC_Projects`, com o **histórico de commits original preservado**. O repositório antigo está arquivado.
